# Faculty Leave Management System

A web-based Faculty Leave Management System developed to simplify and manage the leave application and approval process for faculty members.

## 🚀 Features

- Faculty registration and login
- Secure authentication
- Faculty profile management
- Apply for leave
- View leave history and leave status
- HOD dashboard
- Approve or reject leave applications
- Notifications
- Role-based access control

## 🛠️ Technologies Used

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js
